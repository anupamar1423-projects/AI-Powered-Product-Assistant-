# Product photo sources

The demo catalog includes 16 locally bundled 1600 × 1600 photographic assets in `static/store/images/`. The image files are served locally by Django and Streamlit; the seeded catalog does not require a third-party image host.

These are representative real product/category photographs for the fictional demo SKUs. They are not manufacturer-verified photographs of an exact model being sold. Replace them with owner-supplied photos before using the catalog for actual retail listings.
